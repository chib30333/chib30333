# Setup & Customization

This folder is the source for the **GitHub profile README** that shows on
<https://github.com/chib30333>.

GitHub shows `README.md` from a repository whose name **exactly matches your
username** (`chib30333/chib30333`) at the top of your profile page. That repo
already exists — you just need to push this content into it.

---

## 1. Push it

From `E:\work\Training\github-readme`:

```bash
git init
git add .
git commit -m "Add GitHub profile README"
git branch -M main
git remote add origin https://github.com/chib30333/chib30333.git
git push -u origin main
```

Refresh <https://github.com/chib30333> and the profile README is live.

## 2. Turn on the snake animation

The snake image is generated by a GitHub Action, so it 404s until the workflow
has run once.

1. Repo → **Settings → Actions → General → Workflow permissions** →
   select **Read and write permissions** → Save.
2. Repo → **Actions** tab → **Generate Contribution Snake** → **Run workflow**.
3. It writes `github-snake.svg` and `github-snake-dark.svg` to an `output`
   branch; after that it refreshes itself every 12 hours.

If you would rather not have it, delete the "Contribution Snake" section from
`README.md` and delete `.github/workflows/snake.yml`.

## 3. What to edit

Every spot that needs your own information is marked with `<!-- EDIT ME -->` in
`README.md`. The short list:

| Section | What to change |
| --- | --- |
| Header | The typing lines in the `lines=` parameter (separated by `;`, use `+` for spaces) |
| About Me | The YAML block and bullet list |
| Tech Stack | Delete badges you do not use; add more from [simpleicons.org](https://simpleicons.org) |
| Featured Projects | Change `repo=` to a real repository name; duplicate the block for more |
| Connect With Me | Email, LinkedIn, X, portfolio links — delete unused badges |

### Adding a tech badge

```markdown
![Name](https://img.shields.io/badge/Name-HEXCOLOR?style=for-the-badge&logo=SLUG&logoColor=white)
```

`SLUG` is the icon name from <https://simpleicons.org> (lowercase, no spaces —
e.g. `nodedotjs`, `amazonwebservices`).

## 4. Light + dark mode

Every generated image uses a `<picture>` element:

```html
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="...dark version..." />
  <img src="...light version..." alt="..." />
</picture>
```

GitHub swaps them with the visitor's theme, so the profile looks right either
way. Keep that pattern if you add more cards.

To change the accent colours, search and replace these hex values:

- `58A6FF` — blue (titles, rings)
- `A371F7` — purple (icons, accents)
- `3FB950` — green (points)
- `0D1117` — dark background

## 5. Services used

All are free, third-party and rate-limited — an occasional blank card just means
the service is busy, it usually renders on refresh.

| Service | Used for |
| --- | --- |
| [capsule-render](https://github.com/kyechan99/capsule-render) | Header / footer banners |
| [readme-typing-svg](https://github.com/DenverCoder1/readme-typing-svg) | Animated typing text |
| [shields.io](https://shields.io) | Badges |
| [github-readme-stats](https://github.com/anuraghazra/github-readme-stats) | Stats, top languages, repo pins |
| [github-readme-streak-stats](https://github.com/DenverCoder1/github-readme-streak-stats) | Streak card |
| [github-profile-trophy](https://github.com/ryo-ma/github-profile-trophy) | Trophies |
| [activity-graph](https://github.com/Ashutosh00710/github-readme-activity-graph) | Contribution graph |
| [komarev ghpvc](https://github.com/antonkomarev/github-profile-views-counter) | Profile view counter |
| [Platane/snk](https://github.com/Platane/snk) | Snake animation |

**Private commits:** the stats card is set with `count_private=true`, but that
only counts them if you deploy your own instance of github-readme-stats. On the
public instance it silently shows public activity only.
